LayerMateriald (nm)n

Properties

Mirror reflectance is computed for the as-grown (passive) structure: active layers carry no gain, so there is no threshold-gain spike. "From cavity" means light incident from the cavity layer next to the mirror (taken as lossless), with the phase referenced to the mirror interface.

Incident x =y = 1st layer x =y = 2nd layer x =y = Exit x =y =

Quarter-wave stack at λ0, normal incidence, light arriving from the incident medium onto the 1st layer. For a mirror seen from a GaAs cavity, use GaAs as the incident medium and put the low-index layer first. Penetration depth: Coldren & Corzine eqs. A7.13 and A7.25, with the Ch. 3 approximations for comparison. Analytic R uses ((n0 − Y)/(n0 + Y))², Y = (n1/n2)2m nexit.

Click a point on the plot to see its values and apply it to the design.

Each point is a full threshold analysis (exact outgoing-wave condition) of the design with the chosen input changed; nothing else is re-optimised. The lasing mode is followed from point to point, starting at the current λlas. A layer inside a group changes in every repeat. Round-trip conversion and ηi follow the Results tab settings.
